**Status semantics:** `PROPOSED` (student case/hypothesis), `MENTOR_CONFIRMED` (actual source-linked supervisor decision), `EXECUTED_EXPLORATORY`, `ACCEPTED_CONTROLLED`, `DATA_BLOCKED`, `HUMAN_REVIEW_PENDING`. Do not promote a state from text generated by an AI.

Freeze, in order: decision being evaluated → crop/site/system boundaries → outcome measures and input eligibility → independent reference answer → raw A/B acquisition contract → scoring rubric → review disposition. A named case ID is not itself a confirmed facility.

W1 soil data gate: georeferenced sample ID; depth/date; lab EC units and moisture basis; matched image metadata/bands; independent spatial validation groups and permissions. W2 benchmark: exact 50 questions and licensing, four model labels, frozen instructions, isolated raw runs and five-axis 0–2 rubric from the original materials. W3: eleven subsystems, no equipment sizing without source inputs. W4: fixed packet before retrieval; training only upon demonstrated need.
