# 5 — Supervisor review, obligations and resuming work

This is what an incoming researcher, supervisor, or future self needs to know **without reading chat logs**.

## Who is waiting on whom?
| Decision or input | Responsible party | Current evidence state | Next move |
|---|---|---|---|
| Exact greenhouse QA goal/crop, model-training interpretation, and whether Al-Shahaniya is the chosen case | QEERI mentor / research supervisor | **PROPOSED** in uploaded plan; approval reply not inspected | Bring 1-page scope/question for explicit answer |
| One independently checkable greenhouse source passage, conditions and applicability | Researcher, then qualified reviewer | IFAS general equation checked; exact local paper claims and review incomplete | Review original evidence at a specific locator |
| Valid comparable agricultural LLM run and score | Researcher + independent assessor | Exploratory responses; comparable full run receipts not accepted | Preserve raw data and manually grade against locked key |
| Real greenhouse hourly/sensor data and permissions | Authorized data custodian | NOT ACQUIRED | Ask for a sample raw file + metadata, not fabricated specifications |
| Soil laboratory labels and imagery access | Authorized lab/data custodian | DATA_BLOCKED | Request sample ID/depth/date/EC/moisture and matched scenes |
| Timesheet/internship administrative forms and compliance | Researcher + institutional administrator | User archive contains forms; **submission/approval not inferred** | Check institution's actual receipt privately |

**Current single next move:** record the mentor's scope answer (or an explicit “no response yet”) and the source-specific evidence needed to make the first assessment meaningful. If the mentor cannot respond, complete non-private source verification without treating silence as approval.

## External-facing materials
Supervisor: one page describing original question, scope, one checked example, limits, next decision. Developer: only code + reproducible tests. Potential operator: requirements and unknowns, not a safe equipment recommendation. Public/LinkedIn: only independently supported and permitted findings, no QEERI institutional endorsement or confidential files.
