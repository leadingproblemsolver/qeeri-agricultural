# 03 — User feedback, memory, goals and collaboration

**Research purpose:** prevent evidence and reviewer decisions from disappearing between sessions or people. Multi-party AI agents and multi-agent simulation are **possible extensions, not current QEERI results**.

## Gate to implement
Start ONLY when an actual handoff or repeated-review failure is documented: e.g. a mentor cannot reconstruct a claim's origin or a reviewer disagrees because the previous judgment was lost.

**Minimal vertical slice:** researcher submits one source-linked claim → second human reviewer accepts/rejects with reason → after interruption the next collaborator reconstructs question, source, decision and next evidence request from original files. First test this **manually** with a real authorized reviewer; only then assess a memory/context-pack tool.

**Measure:** missing-context fields, false memories, time to reconstruct, agreement about claim state, unresolved differences and actual reviewer acceptance. Never synthesize acceptance receipts.

### Agent and multi-agent expansion (held)
An AI teammate or multi-agent simulation is justified only if separately defined agent roles and an identical single-agent baseline exist. Preserve message transcripts, delegated actions, human boundaries, information budgets and errors. Without that, **no collaborative-agent research claim**.

**Exit receipt:** source-linked manual handoff, reviewer feedback and difference versus unaided reconstruction. **Industry signal:** evidence-preserving collaboration engineering; not proof of learned user preferences or autonomous teams.
