# Canva presentation: mandatory visual and scientific QA

## Slide claim policy
Every slide should carry `OBSERVED EMAIL / REPO ARTIFACT / REPORTED TEST / PROPOSED / UNKNOWN`. Page references in the accompanying Markdown dossier are the authority over design-generated text.

## Layout checks (pass/fail)
- All five reporting windows labeled **retrospective grouping**, not official payroll/timesheet week numbers.
- Name supervisor Dr. Sa’d Abdel-Halim Shannak and technical reviewer Abdellah Islam Kafi accurately.
- 50-question set **PREPARED**; 200 responses **not verified complete**. Never show '200 tests completed' absent controlled raw evidence.
- RAG/MCP counts (52/52 and 64/64) labeled **reported software tests**, not agronomic score.
- UAV work **design-only**: no flights, EC prediction accuracy or validation charts.
- Test A archival transcription vs raw original; B in-chat source-assisted generation vs clean independent test; no performance uplift graph.
- Source table never implies DOI link proves studied measured values.
- Hypothetical numerical examples visually labeled assumed; include units.
- No fabricated facility photos, charts, greenhouse maps, yield, cost, citations, approvals or reviewer quotes.
- No personal Gmail addresses, private meeting links, book PDF content or internal attachment excerpts published.
- Source and limitation font readable at normal projected scale; no tiny footnotes covering scientific qualifications.
- Final slide has exactly one decision request, reviewer and evidence gate, not an open-ended roadmap.

## Human presentation check
For each displayed conclusion ask: 'Which file? Which line/figure? What do I know independently? What would disprove it? What is still unmeasured?' If any answer is missing, mark `PENDING VERIFICATION`. Reviewer must compare slides directly to archived sources; Canva AI copy itself is unverified.
